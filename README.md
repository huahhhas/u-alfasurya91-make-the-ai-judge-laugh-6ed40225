One office-life joke, one line, under 200 characters — written for make.fun's "Make the AI Judge Laugh" bounty. The program writes the joke deterministically to `entry.txt`: an hour blocked off to mourn the work never done, lost to yet another meeting about meetings.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `OUTPUT_DIR` to write elsewhere:

```sh
OUTPUT_DIR=./out python3 main.py
```
